Every draft from [AI Blog Writer with Sources](/) comes with SEO suggestions: a meta title, a meta description and a slug, written for the brief's reader and search intent. Instead of copying them into your SEO plugin by hand, you can apply them from the editor sidebar. This tutorial shows how, for each supported SEO plugin.

## Which SEO plugins are supported

| SEO plugin | What is applied | Needs |
| --- | --- | --- |
| Rank Math SEO | Meta title, meta description, focus keyword | The free plugin |
| Yoast SEO | SEO title, meta description, focus keyphrase | [AI Blog Writer Pro](/pricing/) |
| All in One SEO | Title, description, focus keyphrase | AI Blog Writer Pro |
| SEOPress | Title, meta description, target keyword | AI Blog Writer Pro |

The **focus keyword** is the brief's **primary phrase**, so fill that field in the brief (or use **Suggest keywords for this topic**) if you want one applied. If more than one supported SEO plugin is active, the first in the table above is used.

## 1. Check the suggestions first

Open the draft in the block editor and open the **AI Blog Writer** sidebar from the toolbar. Under **SEO suggestions** you'll see the suggested meta title, description and slug.

Read them before applying anything. Check that the title and description:

- describe what the article actually says after your edits, not what the draft first said
- contain the primary phrase naturally, once
- fit your SEO plugin's length guidance (it shows a preview once they're applied)
- don't promise anything the article doesn't deliver

## 2. Save your changes

Applying metadata saves it to the post and reloads the editor, so save or discard any unsaved edits first. The sidebar tells you if there are changes to save.

## 3. Apply them

Click **Apply to Rank Math** (or **Apply to Yoast SEO**, **Apply to All in One SEO**, **Apply to SEOPress**). The editor reloads with the values in your SEO plugin's own panel.

**Values you've already set are kept.** If the post already has an SEO title, description or focus keyword in your SEO plugin, the sidebar shows **Replace values already set in …**. Tick it only if you want the suggestions to overwrite them.

## 4. Finish in your SEO plugin

Open your SEO plugin's panel and treat the applied values as a starting point:

- Check the snippet preview and adjust the length.
- Check the slug in the post settings. The draft was created with the suggested slug; shorten it if it's long, before you publish.
- Run your SEO plugin's own checks, then decide what's worth acting on.

## Without a supported SEO plugin

Copy the suggestions from the **SEO suggestions** panel into your theme's or SEO plugin's fields by hand. They're stored with the post, so they're still there when you come back to it.

## Good practice

- **One primary phrase per article.** If two of your posts target the same phrase, they compete. The plugin warns when a new draft has the same title as an existing post.
- **Write for the reader, not the keyword.** A clear description of what the reader gets usually earns more clicks than a keyword-stuffed one.
- **Revisit after editing.** Heavy edits change what the article is about; update the metadata to match.
